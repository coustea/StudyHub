## 题目详情

### 合并两个有序链表

**题目描述**：将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**解题思路**：
- 使用双指针遍历两个链表
- 比较当前节点值，将较小的节点接入结果链表
- 处理剩余节点

**复杂度**：
- 时间复杂度：O(m + n)，其中 m 和 n 分别为两个链表的长度
- 空间复杂度：O(1)
