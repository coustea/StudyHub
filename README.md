# 算法刷题记录

本仓库用于记录日常算法刷题练习，按照算法类型进行分类。

> **注意**：本项目仅用于代码存档和备份，不保证代码在本地 IDE 中能够编译运行。代码均在 LeetCode/AcWing 平台上验证通过。

## 目录结构

```
.
├── README.md
├── linked_list/        # 链表
├── array/              # 数组
├── tree/               # 树
├── graph/              # 图
├── dynamic_programming/ # 动态规划
├── greedy/             # 贪心
├── binary_search/      # 二分查找
├── sort/               # 排序
├── search/             # 搜索
├── stack_queue/        # 栈和队列
├── hash_table/         # 哈希表
├── math/               # 数学
├── string/             # 字符串
├── backtracking/       # 回溯
├── bit_manipulation/   # 位运算
└── others/             # 其他
```

## 解题模板

每道题建议包含：
- 题目名称
- 难度等级
- 题目链接
- 解题思路
- 时间复杂度
- 空间复杂度
- 代码实现
