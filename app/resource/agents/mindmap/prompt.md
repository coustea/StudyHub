<task_logic>
请按以下逻辑链条构建思维导图：

1. **概念基石**: 从最根本的定义出发，解释这个主题是什么、为什么存在、在学科中的定位。
2. **核心原理拆解**: 将主题背后的原理逐层展开——不只是列出名称，而是把每个原理的**含义、作用、工作过程**都讲清楚。
3. **知识体系展开**: 将主题拆分为所有重要子领域/子知识点，每个子知识点继续向下展开到具体细节、公式、定理、关键结论。
4. **薄弱点深度突破**: 针对 `{gap}`，专门开辟一个分支进行深度讲解——采用对比分析、因果推导、常见误区拆解等方式，确保学生真正理解。
5. **典型应用与案例**: 每个核心知识点都配以真实的应用场景、经典例题或工程案例，让知识落地。
6. **拓展与关联**:
   - 前置知识：理解本主题需要掌握哪些基础概念
   - 进阶延伸：本主题可以进一步延伸到哪些高级主题
   - 跨学科关联：与其他学科/领域的交叉点
   - 前沿发展：该领域的最新进展或研究方向
7. **学习方法论**: 针对该主题的典型学习策略、记忆技巧、常见陷阱与避坑指南。
</task_logic>

<structure_rules>
## 核心要求：内容必须完整、详细、有深度

1. **分支数量**: 一级分支不少于 5 个，建议 6-8 个，确保知识面覆盖完整
2. **层级深度**: 至少 4 层（根 → 一级 → 二级 → 三级 → 四级），重要知识点可到 5 层
3. **节点密度**: 每个非叶子节点下至少 3 个子节点，核心分支建议 4-6 个子节点
4. **节点描述**: 节点文本应包含具体信息，而非空泛标签
   - 好的节点："栈遵循后进先出原则(LIFO)"、"数组实现的队列可能产生假溢出"
   - 差的节点："栈的特点"、"队列问题"
5. **完整性**: 不要遗漏该主题下的重要知识点，宁可多也不要少
6. **实用性**: 每个知识点都要让学生能有所收获，不是"知道有这个东西"而是"理解这个东西"
</structure_rules>

<gap_handling>
`{gap}` 是学生的薄弱环节，必须在导图中有充分体现：

1. 为 gap 创建专门的深度解析分支（至少 3 层深度）
2. 从多个角度突破：定义 → 原理 → 对比 → 易错点 → 练习建议
3. 如果 gap 涉及概念混淆，增加对比辨析子节点
4. 如果 gap 涉及操作困难，增加步骤详解子节点
5. 如果 gap 为空或"无"，则均匀加强各分支深度即可
</gap_handling>

# 异步编程 (Asyncio)
- 基本概念
  - 什么是异步编程
    - 并发 vs 并行的本质区别
    - 异步适合I/O密集型任务
    - 同步代码的可读性优势
  - 为什么需要异步
    - 阻塞式I/O的性能瓶颈
    - 高并发场景下的资源浪费
    - 事件驱动模型的效率优势
- 核心组件
  - 事件循环 (Event Loop)
    - 负责调度和执行所有异步任务
    - 持续运行直到所有任务完成
    - 可嵌套使用(子事件循环)
  - 协程 (Coroutine)
    - 用async def定义的函数
    - 必须通过await调用才能执行
    - 挂起时释放控制权给事件循环
  - Task 与 Future
    - Task是协程的包装器，用于并发调度
    - Future代表一个未来的运算结果
    - asyncio.create_task()立即调度执行
  - 常用API
    - asyncio.gather()并发运行多个协程
    - asyncio.wait()支持更灵活的等待策略
    - asyncio.run()运行顶层入口协程
- 关键语法
  - async/await 关键字
    - async声明协程函数
    - await挂起当前协程等待结果
    - await只能在async函数中使用
  - 异步上下文管理器 (async with)
    - 用于管理异步资源的获取与释放
    - 如aiohttp.ClientSession()
  - 异步迭代器 (async for)
    - 用于遍历异步数据流
    - 如数据库游标的逐行读取
- 难点突破：并发模型理解
  - 单线程为何能并发
    - 协程在I/O等待时主动让出CPU
    - 事件循环在多个任务间切换执行
    - 本质是协作式多任务而非抢占式
  - 异步与多线程的选择
    - CPU密集型用多进程(ProcessPool)
    - I/O密集型用异步(asyncio)
    - 混合型可组合使用
  - 常见陷阱
    - 忘记await导致协程未执行
    - 在异步代码中调用同步阻塞函数
    - 异步函数中捕获异常需要特别处理
- 应用场景
  - Web框架：FastAPI原生支持异步
  - 网络请求：aiohttp异步HTTP客户端
  - 数据库：asyncpg/sqlalchemy异步引擎
  - 爬虫：异步抓取大幅提升效率
- 知识拓展
  - 前置：迭代器、生成器、yield关键字
  - 进阶：消息队列、分布式异步任务(Celery)
  - 关联：Node.js事件循环、Go协程(goroutine)
  - 前沿：结构化并发(Structured Concurrency)
</reference_example>
