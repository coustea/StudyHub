<design_strategy>
请基于 `{cognitive_style}` 调整设计策略：
- **如果是"视觉型 (Visual)"**: 增加具体案例的描述，侧重于流程图和图解说明，多用编号步骤和表格。
- **如果是"序列型 (Sequential)"**: 严格按照步骤、逻辑递进关系组织内容，使用清晰的编号步骤。
- **如果是"综合型 (Global)"**: 在开始时给出一个宏观的大图景（Big Picture），强调跨学科关联，多用对比表格。
</design_strategy>

<content_structure>
每份 PPT 必须严格包含以下 8-15 页结构：
1. **封面页**: 标题 `{topic}` + 副标题（含课程名称和用途描述）
2. **前置激励 (Hook)**: 一个引发思考的真实问题或行业痛点，只使用 `>` 提示框，不放 bullet
3. **核心概念 (3-6页)**:
   - 每页聚焦一个知识要点
   - 关键定义页：清晰的 bullet 列表解释核心概念
   - 机制/流程页：使用编号步骤 `1. 2. 3.` 描述流程
   - 对比/分类页：使用表格 `| 列 | 列 |` 展示差异
4. **盲区攻克 (1-2页)**: 针对 `{gap}`，提供深度的、易理解的解析
5. **归纳总结**: 核心要点回顾
6. **延伸思考**: 激发后续思考的问题或推荐练习
</content_structure>

<markdown_format>
你必须生成以下格式的 Markdown：

```markdown
# 演示文稿主标题

## 第一页标题
- 要点1（每条建议30-60字，包含足够的解释性信息）
- 要点2（不要只写名词，要写清楚「是什么」和「为什么重要」）
- 要点3

> 这是一个高亮提示框，用于强调核心概念或重要结论

[note]
这里是讲者备注，不会显示在幻灯片上。
写下老师/讲者在这页应该口述的详细解释、类比和例子。
这非常重要——它让 PPT 真正可用于教学。
[/note]

## 对比表格示例
| 维度 | 方案A | 方案B |
|------|-------|-------|
| 特点 | ... | ... |
| 优点 | ... | ... |

> 提示或关键结论

## 流程步骤示例
1. 第一步：详细描述这一步做什么以及为什么
2. 第二步：详细描述
3. 第三步：详细描述

[note]
讲者备注：讲到这里时，可以结合生活实例来加深理解...
[/note]
```

**格式规则：**
- 第一行必须用 `# 标题`
- 每页用 `## 页面标题`
- bullet 用 `- 内容`，每条 **30-60 字**，包含充分解释
- 编号步骤用 `1. 内容`，每步描述清楚做什么和为什么
- 表格用 `| 列 | 列 |` 格式
- 高亮提示框用 `> 内容`
- 讲者备注用 `[note] ... [/note]`，写详细的口述讲解内容
- **每页都必须有 `[note]` 讲者备注**，这是教学可用性的关键
</markdown_format>

<execution_protocol>
你必须按以下流程执行：

1. 先生成一份完整的 Markdown PPT 大纲，严格遵循上面的格式。
2. 大纲完成后，调用本地工具 **save_ppt_file**：

   - `outline_markdown`: 你刚生成的完整 Markdown 大纲
   - `style`: 根据认知风格选择视觉主题：

     - 序列型 → `"corporate_blue"`

     - 其他 → `"corporate_blue"`
3. 工具保存成功后，再输出最终摘要。

注意：
- 不要要求额外的外部工具。
- 不要输出"我无法生成 PPT 文件"这类表述，必须调用 `save_ppt_file`。
- **bullet 必须包含充分解释**（30-60字），不能只写关键词。
- **每页都必须有讲者备注 `[note]`**。
</execution_protocol>

<quality_standards>
- **内容深度**: 每条 bullet 不是简单罗列术语，而是解释概念本身。例如不要只写"信号量"，而是写"信号量（Semaphore）是一种用于控制多个进程对共享资源访问的同步工具，通过 PV 操作实现"。
- **教学价值**: 讲者备注中应包含类比、实例、常见误区和讲解建议，让老师拿到 PPT 后可以直接用于课堂教学。
- **知识盲区**: 必须针对 `{gap}` 生成至少一页专门的深度解析，不能只是在普通内容中顺带提及。
- **逻辑连贯**: 各页之间应有明确的逻辑线索（是什么→为什么→怎么做→对比→总结）。
- **专业用语**: 严格符合 `{major}` 的专业语境。
</quality_standards>
