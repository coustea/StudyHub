# Branch Patterns

Use this file when the request is clear but the branch layout is not obvious. Pick one pattern and adapt it; do not merge all of them.

## Review pattern

Best for after-class consolidation or chapter review.

```markdown
# Topic
- 概念定义
- 核心组成
- 关键机制
- 易错点
- 快速回顾
```

## Exam pattern

Best for short-term score improvement or targeted revision.

```markdown
# Topic
- 高频考点
- 对比辨析
- 易错点
- 题型策略
- 快速记忆
```

## Deep-understanding pattern

Best for principle-focused or research-style learning.

```markdown
# Topic
- 概念定义
- 底层原理
- 机制链路
- 边界限制
- 延伸拓展
```

## Practice pattern

Best for coding, experiments, or operational tasks.

```markdown
# Topic
- 使用场景
- 操作流程
- 关键步骤
- 常见错误
- 实战建议
```

## Weak-point branch ideas

Choose one or two of these when `gap` is important:

- 难点突破
- 对比辨析
- 原理拆解
- 步骤详解
- 常见卡点
- 易错点
- 调试思路

## Balancing rules

- Prefer 3-5 first-level branches
- Prefer parallel labels at the same depth
- Keep extension branches smaller than the core branches
- If one branch grows much larger than the others, split or compress it
