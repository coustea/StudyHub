# 算法学习路线

本文档提供系统化的算法学习路线，帮助从零开始逐步掌握算法和数据结构。

## 📊 学习路线图

```
基础语法 (1-2周)
    ↓
基础数据结构 (2-3周)
    ↓
基础算法 (3-4周)
    ↓
进阶数据结构 (2-3周)
    ↓
进阶算法 (4-6周)
    ↓
综合应用 (持续)
```

---

## 🎯 第一阶段：基础语法 (1-2周)

### 学习目标
- 熟悉编程语言基础
- 掌握基本输入输出
- 理解变量、循环、条件语句

### 重点内容
- C++ / Python / Java 基础语法
- STL 基本使用（C++）
- 复杂度分析（时间复杂度、空间复杂度）

### 推荐题目
- 输入输出练习
- 简单计算题
- 条件判断题
- 循环练习题

## 🎯 第二阶段：基础数据结构 (2-3周)

**重要性**：⭐⭐⭐⭐⭐

**推荐题目类型**：
- 有效的括号

#### 3. 链表 ⭐⭐⭐
**重要性**：⭐⭐⭐⭐

**核心知识点**：
- 单链表的基本操作
- 双链表
- 链表的遍历、插入、删除

**推荐题目类型**：
- 合并两个有序链表
- 删除链表的倒数第N个节点

#### 4. 哈希表 ⭐⭐
**重要性**：⭐⭐⭐⭐⭐

## 💡 学习建议

### 1. 刷题原则
- **质量 > 数量**：理解一道题胜过囫囵吞枣十道题
- **重复**：重要的题目要反复做
- **总结**：每道题都要总结思路和技巧
- **分类**：按题型刷题，形成知识体系

### 2. 刷题节奏
- **每天**：至少 1-2 道题
- **每周**：复习本周做过的题
- **每月**：总结本月学习的内容

### 3. 解题步骤
1. **理解题意**：明确输入输出和题目要求
2. **分析思路**：思考用什么数据结构和算法
3. **编写代码**：先写伪代码，再写正式代码
4. **测试调试**：考虑边界情况和特殊用例
5. **总结优化**：思考是否有更好的解法

### 4. 进阶技巧
- 一题多解
- 优化代码
- 学习别人的优秀解法
- 定期复习

## 📅 学习时间规划（建议）

### 快速通道（3个月）
适合有编程基础的快速学习

**第 1 个月**：基础 + 简单数据结构
- 第 1 周：基础语法、复杂度分析
- 第 2 周：数组、字符串、哈希表
- 第 3 周：栈、队列、链表
- 第 4 周：排序、二分查找

**第 2 个月**：基础算法 + 树
- 第 1 周：DFS、BFS
- 第 2 周：树的基本操作
- 第 3 周：二叉搜索树、堆
- 第 4 周：回溯算法

**第 3 个月**：进阶算法
- 第 1-2 周：动态规划入门
- 第 3-4 周：贪心、图论

### 标准通道（6个月）
适合基础薄弱或时间充裕的学习者

每个阶段时间翻倍，增加练习题量，注重理解和巩固。
