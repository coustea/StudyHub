# 数组与切片

数组长度固定，切片长度可变。实际开发中切片远多于数组，但理解数组是理解切片的前提。

## 数组

### 声明与初始化

```go
var a [3]int              // [0 0 0]
var b [3]int = [3]int{1, 2, 3}
c := [3]int{1, 2}         // [1 2 0]
d := [...]int{1, 2, 3, 4} // 编译器推断长度为 4
```

`[...]` 让编译器根据元素个数推断长度。

指定索引初始化：

```go
a := [5]int{0: 10, 4: 20} // [10 0 0 0 20]
```

### 数组是值类型

数组赋值和传参会**复制整个数组**：

```go
a := [2]int{1, 2}
b := a
b[0] = 99
fmt.Println(a) // [1 2]
fmt.Println(b) // [99 2]
```

这也是数组很少直接作为参数传递的原因——大数组复制成本高。

### 多维数组

```go
var matrix [2][3]int
matrix[0][1] = 5
```

## 切片

切片是对数组的**抽象视图**，包含三个要素：指向底层数组的指针、长度 `len`、容量 `cap`。

### 创建切片

```go
s := []int{1, 2, 3}       // 字面量
s2 := make([]int, 3)      // 长度 3，容量 3
s3 := make([]int, 3, 10)  // 长度 3，容量 10
```

从数组或切片切出：

```go
arr := [5]int{1, 2, 3, 4, 5}
s := arr[1:4]   // [2 3 4]，长度 3，容量 4
s2 := arr[:3]   // [1 2 3]
s3 := arr[2:]   // [3 4 5]
s4 := arr[:]    // 全部
```

区间是**左闭右开** `[low:high)`，还可以指定容量上限：

```go
s := arr[1:3:4] // 长度 2，容量 3
```

### len 与 cap

```go
s := make([]int, 3, 5)
fmt.Println(len(s), cap(s)) // 3 5
```

`len` 是当前元素个数，`cap` 是从起始位置到底层数组末尾的可用空间。

### append

```go
s := []int{1}
s = append(s, 2, 3)
s = append(s, []int{4, 5}...)
```

当容量不足时，`append` 会分配新的底层数组（通常扩容为原来的 2 倍，元素较多时策略不同），因此**必须接收返回值**。

```go
s := make([]int, 2, 2)
t := append(s, 3)
fmt.Println(len(s), len(t)) // 2 3
```

`s` 仍指向旧数组，长度不变。

### 切片共享底层数组

```go
a := []int{1, 2, 3, 4}
b := a[1:3]
b[0] = 99
fmt.Println(a) // [1 99 3 4]
```

修改 `b` 会影响 `a`，因为它们共享同一块底层数组。若需要独立副本，用 `copy`：

```go
b := make([]int, len(a))
copy(b, a)
b[0] = 99
fmt.Println(a) // [1 2 3 4]
```

也可以一行搞定：

```go
b := append([]int(nil), a...)
```

### nil 切片与空切片

```go
var a []int          // nil 切片，len=0 cap=0
b := []int{}         // 空切片，len=0 cap=0
c := make([]int, 0)  // 空切片

fmt.Println(a == nil) // true
fmt.Println(b == nil) // false
```

两者行为几乎一致，`append`、`len`、`range` 都可以用。判断空只需 `len(s) == 0`。

### 多维切片

切片的每个元素本身也可以是切片，且长度可以不同：

```go
matrix := [][]int{
    {1, 2},
    {3, 4, 5},
}
fmt.Println(matrix[1][2]) // 5
```

## 性能提示

- 已知长度时用 `make([]T, 0, n)` 预分配容量，减少扩容复制。
- 大切片截取小切片后长期持有，会导致底层大数组无法回收。可用 `append([]T(nil), sub...)` 拷贝出独立小切片。

```go
func subset(big []int) []int {
    small := big[:10]
    return append([]int(nil), small...) // 独立底层数组
}
```

## 小结

| 特性 | 数组 | 切片 |
|---|---|---|
| 长度 | 固定，类型的一部分 | 可变，运行时确定 |
| 赋值语义 | 值复制 | 引用底层数组 |
| 字面量 | `[3]int{...}` | `[]int{...}` |
| 常用场景 | 固定大小、矩阵 | 绝大多数序列场景 |
