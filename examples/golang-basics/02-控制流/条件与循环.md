# 条件与循环

Go 只有一种循环关键字 `for`，没有 `while` 和 `do-while`。条件语句也不需要括号包裹表达式。

## if 语句

```go
age := 18

if age >= 18 {
    fmt.Println("成年")
} else {
    fmt.Println("未成年")
}
```

注意：`if` 后的 `{` 必须与条件在同一行，否则编译错误。这是 Go 强制的格式规范。

### 带初始化语句

`if` 支持在条件前加一条初始化语句，作用域仅限该 if 块：

```go
if score := 85; score >= 60 {
    fmt.Println("及格", score)
} else {
    fmt.Println("不及格", score)
}
```

这种写法常用于处理函数返回的错误：

```go
if v, err := strconv.Atoi("42"); err == nil {
    fmt.Println(v)
}
```

### 多分支

```go
if score >= 90 {
    fmt.Println("A")
} else if score >= 80 {
    fmt.Println("B")
} else {
    fmt.Println("C")
}
```

Go 中 `else if` 必须紧跟前一个 `}` 所在行。

## for 循环

### 标准形式

```go
for i := 0; i < 10; i++ {
    fmt.Println(i)
}
```

三个部分都可以省略：

```go
i := 0
for ; i < 5; {
    i++
}
```

### 省略分号的写法（相当于 while）

```go
for condition {
    // 循环体
}
```

### 无限循环

```go
for {
    // 需要用 break 退出
}
```

## range 遍历

`range` 可以遍历数组、切片、字符串、map 和 channel：

```go
nums := []int{10, 20, 30}

for index, value := range nums {
    fmt.Println(index, value)
}
```

不需要索引时用 `_` 忽略：

```go
for _, value := range nums {
    fmt.Println(value)
}
```

只取索引：

```go
for i := range nums {
    fmt.Println(i)
}
```

遍历 map 时返回键值对，顺序是**不保证**的：

```go
for key, value := range map[string]int{"a": 1, "b": 2} {
    fmt.Println(key, value)
}
```

遍历字符串时返回字节索引和 `rune`：

```go
for i, r := range "你好" {
    fmt.Println(i, string(r)) // 0 你 / 3 好
}
```

## break 与 continue

```go
for i := 0; i < 10; i++ {
    if i == 3 {
        continue // 跳过本次
    }
    if i == 8 {
        break    // 退出循环
    }
    fmt.Println(i)
}
```

### 标签（label）

需要跳出多层循环时使用标签：

```go
Outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if i*j == 4 {
            break Outer
        }
    }
}
```

标签放在循环前，以冒号结尾。`continue Outer` 则会继续执行外层循环的下一次迭代。

## 常见陷阱

### 循环变量捕获

Go 1.22 之前，循环变量在整个循环中是同一个变量，闭包捕获会出错：

```go
for i := 0; i < 3; i++ {
    go func() {
        fmt.Println(i) // 旧版本可能全部输出 3
    }()
}
```

Go 1.22 起每次迭代都有独立变量，问题已修复。若需要兼容旧版本，显式传参：

```go
for i := 0; i < 3; i++ {
    go func(n int) { fmt.Println(n) }(i)
}
```

### 遍历时修改切片

`range` 在循环开始时确定长度，循环中追加的元素不会被遍历到：

```go
s := []int{1, 2}
for _, v := range s {
    s = append(s, v)
}
// 只遍历原来的两个元素
```

## 小结

- `if` 支持初始化语句，适合处理错误和局部变量。
- Go 只有 `for`，可表达三种循环形式。
- `range` 返回索引和值（map 返回键和值），顺序不保证时不要依赖它。
- 多层循环跳转用标签。
