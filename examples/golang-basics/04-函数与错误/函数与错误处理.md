# 函数与错误处理

Go 的函数支持多返回值，错误处理采用显式返回 `error` 的方式，而不是异常机制。这是 Go 代码风格最显著的特征之一。

## 函数定义

```go
func add(a int, b int) int {
    return a + b
}
```

相邻同类型参数可以简写：

```go
func add(a, b int) int {
    return a + b
}
```

无返回值：

```go
func greet(name string) {
    fmt.Println("Hello", name)
}
```

## 多返回值

```go
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("除数不能为零")
    }
    return a / b, nil
}
```

调用时必须处理所有返回值：

```go
result, err := divide(10, 3)
if err != nil {
    return err
}
fmt.Println(result)
```

不需要的值用 `_` 忽略：

```go
result, _ := divide(10, 3)
```

## 命名返回值

返回值可以有名字，函数开始时初始化为零值：

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return // 裸返回，返回 x 和 y
}
```

命名返回值便于文档化，也常与 defer 配合修改返回值，但不宜滥用——函数较长时裸返回会降低可读性。

## 可变参数

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

sum(1, 2, 3)
sum([]int{1, 2, 3}...) // 展开切片
```

## 函数是一等公民

函数可以赋值给变量、作为参数传递、作为返回值：

```go
func apply(f func(int) int, v int) int {
    return f(v)
}

result := apply(func(x int) int { return x * 2 }, 21)
```

## 闭包

闭包是捕获了外部变量的函数：

```go
func counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

c := counter()
fmt.Println(c()) // 1
fmt.Println(c()) // 2
```

闭包常用于封装状态和实现函数式选项模式。

## 递归

```go
func factorial(n int) int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n-1)
}
```

Go 的栈会动态扩容，不需要担心递归深度限制，但仍要注意算法复杂度。

## error 接口

Go 用内置的 `error` 接口表示错误：

```go
type error interface {
    Error() string
}
```

创建错误：

```go
err := errors.New("something went wrong")
err := fmt.Errorf("invalid age: %d", age)
```

## 错误处理惯用法

### 立即检查

```go
f, err := os.Open("file.txt")
if err != nil {
    return err
}
defer f.Close()
```

错误应该在处理它的层级添加上下文，而不是层层包装相同的文字。

### 包装错误

Go 1.13 起用 `%w` 包装错误，保留错误链：

```go
if err != nil {
    return fmt.Errorf("读取配置失败: %w", err)
}
```

之后可以用 `errors.Is` 和 `errors.As` 判断：

```go
if errors.Is(err, os.ErrNotExist) {
    // 文件不存在
}

var pathErr *os.PathError
if errors.As(err, &pathErr) {
    fmt.Println(pathErr.Path)
}
```

### 自定义错误类型

```go
type ValidationError struct {
    Field string
    Msg   string
}

func (e *ValidationError) Error() string {
    return fmt.Sprintf("%s: %s", e.Field, e.Msg)
}
```

调用方可用 `errors.As` 取出具体类型做针对性处理。

### 哨兵错误

包级别定义可比较的错误变量：

```go
var ErrNotFound = errors.New("not found")

func find() error { return ErrNotFound }

if errors.Is(err, ErrNotFound) {
    // 处理
}
```

## 不要忽略错误

```go
// 不推荐
value, _ := strconv.Atoi(input)

// 推荐
value, err := strconv.Atoi(input)
if err != nil {
    return fmt.Errorf("解析数字失败: %w", err)
}
```

只有明确知道错误不可能发生或无关紧要时才可以忽略，并加注释说明原因。

## panic 与 recover 的定位

- `error`：预期的失败（网络错误、参数非法、文件不存在），由调用方处理。
- `panic`：程序无法继续的严重错误（数组越界、nil 解引用），通常由运行时触发。
- 库代码不应该 panic，应返回 error。
- 服务入口可以用 `recover` 兜底，避免整个进程崩溃，但业务代码不应依赖它做流程控制。

```go
func safeRun(fn func()) {
    defer func() {
        if r := recover(); r != nil {
            log.Printf("panic recovered: %v", r)
        }
    }()
    fn()
}
```

## 小结

- Go 函数支持多返回值，最后一个通常是 `error`。
- `...T` 表示可变参数，调用时用 `slice...` 展开。
- 闭包捕获外部变量，用于封装状态。
- 用 `%w` 包装错误，用 `errors.Is` / `errors.As` 判断错误链。
- 显式处理每个错误，不要忽略。
- panic 保留给真正不可恢复的情况。
