# 基本数据类型

Go 的类型系统分为**基本类型**和**复合类型**。本篇只讨论基本类型，复合类型见后续章节。

## 数值类型

### 整数

| 类型 | 范围 |
|---|---|
| `int` | 平台相关，32 位或 64 位 |
| `int8` / `int16` / `int32` / `int64` | 明确位数的有符号整数 |
| `uint` / `uint8` / `uint16` / `uint32` / `uint64` | 无符号整数 |
| `uintptr` | 存储指针地址的整数类型 |

`byte` 是 `uint8` 的别名，`rune` 是 `int32` 的别名，分别表示字节和 Unicode 码点。

```go
var a int = 10
var b int64 = int64(a)
```

日常开发优先使用 `int`，只有需要明确内存布局或跨平台一致性时才用定长类型。

### 浮点数

```go
var f32 float32 = 3.14
var f64 float64 = 3.141592653589793
```

`float64` 是默认推断类型，精度更高，优先使用。

### 复数（了解）

```go
var c complex128 = 1 + 2i
fmt.Println(real(c), imag(c)) // 1 2
```

## 布尔与字符串

```go
var ok bool = true

var s string = "Hello"
var t string = `第一行
第二行` // 原始字符串，保留换行和缩进
```

双引号字符串支持转义，反引号原始字符串不转义，常用于写正则、JSON 模板。

字符串是**不可变**的字节序列，不能用 `s[0] = 'H'` 修改。修改需要转换为 `[]byte` 或 `[]rune`：

```go
s := "hello"
b := []byte(s)
b[0] = 'H'
fmt.Println(string(b)) // Hello
```

## 字符与 Unicode

```go
var ch rune = '中'
fmt.Printf("%c %d\n", ch, ch) // 中 20013

for i, r := range "你好" {
    fmt.Println(i, string(r))
}
```

`range` 遍历字符串时返回的是字节索引和 `rune`，因此中文字符的索引不会连续递增。

## 类型别名与自定义类型

```go
type MyInt int        // 新类型，需要显式转换
type Byte = uint8     // 别名，完全等价
```

自定义类型可以有自己的方法，别名不行。

## 格式化输出

```go
fmt.Printf("%d %s %.2f %t\n", 10, "Go", 3.14159, true)
```

常用占位符：

| 占位符 | 含义 |
|---|---|
| `%d` | 十进制整数 |
| `%s` | 字符串 |
| `%q` | 带引号的字符串 |
| `%f` / `%.2f` | 浮点数 / 保留两位小数 |
| `%t` | 布尔值 |
| `%v` | 任意值的默认格式（最常用） |
| `%+v` | 结构体带字段名输出 |
| `%T` | 值的类型 |
| `%p` | 指针地址 |

调试时 `%v` 和 `%+v` 最省事：

```go
user := struct{ Name string; Age int }{"Alice", 18}
fmt.Printf("%v | %+v | %T\n", user, user, user)
```

## 类型零值回顾

```go
var i int       // 0
var f float64   // 0
var b bool      // false
var s string    // ""
```

掌握了基本类型，就可以开始写条件判断和循环了。
