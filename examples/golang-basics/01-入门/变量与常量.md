# 变量与常量

Go 是静态类型语言，变量声明后类型不可变。它提供了多种声明方式，核心原则是**明确、简洁、避免未使用的变量**。

## 声明变量

标准形式：

```go
var name string = "Alice"
var age int = 18
```

类型可以省略，由编译器推断：

```go
var name = "Alice"
var age = 18
```

一次声明多个：

```go
var (
    name string = "Alice"
    age  int    = 18
)
```

## 短变量声明

函数内部可以使用 `:=`，这是最常用的方式：

```go
func main() {
    name := "Alice"
    age := 18
    fmt.Println(name, age)
}
```

`:=` 的限制：

- 只能在函数内部使用，包级别不行。
- 左侧至少有一个新变量，否则编译报错。

```go
a, b := 1, 2
a, c := 3, 4   // c 是新变量，a 被重新赋值，合法
a, b := 5, 6   // 没有新变量，编译错误
```

> Go 会报 `declared and not used` 错误：声明了却不使用的变量、导入却未使用的包都会导致编译失败。这是 Go 保持代码整洁的重要机制。

## 零值

未显式初始化的变量会得到类型的**零值**：

| 类型 | 零值 |
|---|---|
| `int` / `float64` | `0` / `0.0` |
| `bool` | `false` |
| `string` | `""` |
| `pointer` / `slice` / `map` | `nil` |

```go
var count int      // 0
var flag bool      // false
var name string    // ""
```

Go 没有"未初始化变量"的概念，这消除了很多类空指针问题。

## 类型转换

Go 要求显式转换，不支持隐式类型转换：

```go
var i int = 42
var f float64 = float64(i)
var u uint = uint(i)

// i = f  // 编译错误
```

转换时若目标类型范围不足，值会被截断（运行时不报错），需要自行注意。

## 常量

`const` 声明编译期常量，可以是数字、字符串、布尔值：

```go
const Pi = 3.14159
const Greeting = "Hello"

const (
    Monday = 1
    Tuesday = 2
)
```

常量不能在运行期赋值，也不能取地址。

## iota 枚举

`iota` 是常量组中的自增计数器，从 `0` 开始，每出现一行常量声明就加一：

```go
type Weekday int

const (
    Sunday Weekday = iota  // 0
    Monday                // 1
    Tuesday               // 2
    Wednesday             // 3
)
```

可以配合表达式跳过某些值：

```go
const (
    _  = iota             // 跳过 0
    KB = 1 << (10 * iota) // 1 << 10
    MB                    // 1 << 20
    GB                    // 1 << 30
)
```

## 作用域

- 包级变量：函数外声明，整个包可见。
- 局部变量：函数或代码块内声明，块结束后销毁。
- 内层作用域可以遮蔽外层同名变量，但不建议滥用。

```go
var x = 10

func main() {
    x := 20      // 遮蔽包级 x
    {
        x := 30  // 再次遮蔽
        fmt.Println(x) // 30
    }
    fmt.Println(x)     // 20
}
```

## 小结

- 函数内优先用 `:=`，包级用 `var`，固定值用 `const`。
- 零值机制保证变量始终有确定状态。
- 未使用的变量和包会导致编译失败。
- `iota` 是定义枚举和位标志的惯用方式。
